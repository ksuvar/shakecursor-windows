# Breeze cursors for Windows

These `.cur` / `.ani` files are the KDE Plasma 6 Breeze cursor theme converted to Windows format by
[black7375/Breeze-Cursors-for-Windows](https://github.com/black7375/Breeze-Cursors-for-Windows)
(release v1.0.0, `plasma6.zip`, with contributions from IceflowRE), based on az4521's original port.

They are redistributed unmodified under the Creative Commons Attribution 3.0 Unported license; see
[LICENSE-CC-BY-3.0.txt](LICENSE-CC-BY-3.0.txt). The Breeze cursor artwork itself comes from the
[KDE Breeze project](https://invent.kde.org/plasma/breeze).
